# 双目测波系统设计

## 系统组成

系统由两台同步相机、刚性基线、标定目标、时间同步单元、采集存储单元和 WASS 处理环境组成。相机应具有足够的重叠视场，并尽量避免运动模糊、过曝和强烈镜面反射。

## 数据流

1. 同步采集左右图像与时间戳。
2. 完成内参、畸变和双目外参标定。
3. 对图像去畸变并进行极线校正。
4. 调用 WASS 完成立体匹配和稠密三维重建。
5. 将点云转换为规则水面或逐像素高度图。
6. 输出高度、置信度、有效区域与误差指标。

## 接口原则

本项目通过文件或命令行接口调用已安装的 WASS。WASS 源码保持上游状态；版本、构建参数和运行配置需单独记录，以确保结果可复现。
