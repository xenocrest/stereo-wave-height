# 项目概述

## 目标

构建一个基于 WASS 的双目立体测波研究项目，将同步双目图像中的水面像素转换为相机坐标系或世界坐标系中的三维点，并进一步解算相对于参考水面的像素级海浪高度。

## 当前阶段进展

当前已完成手机双目真实视频链路验证：

1. 接入 OpenCV 官方双目标定流程，完成 K/D/R/T 求解。
2. 使用人工测量 baseline 对标定结果进行独立物理一致性验证。
3. 完成 OpenCV 标定结果到 WASS 固定标定流程的接口适配。
4. 完成静水面三维重建测试，验证从视频输入到三维点云输出的完整链路。
5. 定位当前主要瓶颈为近距离弱纹理水面场景下 StereoSGBM 匹配稳定性，而非标定或坐标转换问题。

当前状态：

- 标定参数：已获得并完成物理一致性检查；
- WASS 接口：已完成固定标定接入；
- 静水重建：单帧水面平面恢复成功；
- 跨帧稳定性：仍需优化双目匹配参数和物理视差约束。

## 范围

项目覆盖双目标定、影像校正、立体对应、三角测量、水面建模、高度定义、质量控制和误差分析。采集视频、大型数据集与 WASS 源码不属于本仓库的版本控制范围。

## 预期产出

1. 可追溯的系统与数学模型文档。
2. 与 WASS 输出对接的处理模块。
3. 像素级高度图、三维水面点云及质量掩膜。
4. 使用合成数据和实测数据的精度评估流程。
