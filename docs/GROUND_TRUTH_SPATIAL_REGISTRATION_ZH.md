# 独立真值传感器空间配准

设备到货后，在双目重建坐标系中选取可重复识别的控制点，记录控制点在视觉坐标系和物理量测坐标系的成对坐标，求解并核查刚体变换，然后实测每个传感器测量点的位置。把位置变换至最终 `official_grid_m` 坐标，保存 `sensor_layout.yaml` 的 `x_mm、y_mm、z_datum_mm`、量测方法和原始记录。不能把图像中央当作传感器位置，也不能凭目测填入坐标。

若使用 `H_true_mm`，传感器高度零位必须与 `reference_plane_id` 相同。若使用 `Z_true_mm`，该 Z 必须已经在 `official_grid_m` 坐标中；验证程序按同一固定面计算高度。坐标系或零位不一致时结果为 `REFERENCE_DATUM_MISMATCH`。近邻视觉点仅在配置的最大空间距离内被接受，输出真实 `x_vision、y_vision、x_gt、y_gt、spatial_distance_mm`。门限取值在看真值结果前依据传感器尺寸、点位测量误差和官方网格间距记录。

新相机安装、分辨率或镜头设置变化后，重测控制点和传感器位置。控制点本身不用于按真值调整 WASS 重建。
