# 研究方向

## 核心问题

- 如何稳定完成低纹理、高反光、动态水面的双目匹配。
- 如何从视差与标定参数得到带有不确定度的三维水面。
- 如何定义局部参考水面并将三维点转换为像素级波面高度。
- 如何分离标定、同步、匹配、姿态和参考面误差。

## 当前研究进展

### 1. 双目标定与工程参数验证

已完成 OpenCV 官方双目标定流程接入，并获得完整内参、畸变参数和双目外参。

通过人工测量 baseline、相机高度和俯角进行物理一致性检查：

- 标定 baseline：68.6847 mm；
- 人工测量 baseline：70.0000 mm；
- 相对误差：约 1.88%。

结论：人工测量参数仅作为物理 sanity check，不替代标定结果。实际重建优先使用标定得到的 K/D/R/T。

### 2. WASS 工程接入

已完成 OpenCV 标定结果到 WASS 输入格式的适配流程。

当前已解决：

- OpenCV 与 WASS 坐标约定统一；
- rectification 参数接口适配；
- 固定标定参数进入 WASS stereo 流程；
- 手机视频作为 Stereo Video File 输入验证。

### 3. 真实手机视频静水重建验证

已完成 HomeTank_004 静水面三维重建验证。

结果：

- 单帧可恢复稳定水面平面；
- 跨帧水面深度存在漂移。

当前判断主要原因：

- StereoSGBM 匹配稳定性不足；
- 手机近距离拍摄导致视差接近搜索上限；
- 水面纹理弱，导致有效匹配区域变化。

目前未进入 wave 解算阶段，正在先解决静态几何稳定性问题。

## 后续路线

1. 基于已知物理几何约束继续优化 StereoSGBM 匹配稳定性；
2. 完成静水面跨帧稳定重建验证；
3. 在静水基准稳定后进入人工波视频处理；
4. 后续迁移至专业双目工业相机，复用已建立的标定、WASS 接口和质量控制流程。
