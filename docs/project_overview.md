# 项目概述

## 目标

构建一个基于 WASS 的双目立体测波研究项目，将同步双目图像中的水面像素转换为相机坐标系或世界坐标系中的三维点，并进一步解算相对于参考水面的波浪高度。

## 当前阶段进展

当前已完成手机双目真实视频链路验证：

1. 接入 OpenCV 官方双目标定流程，完成相机内参、畸变参数和双目外参 K/D/R/T 求解。
2. 使用人工测量 baseline、相机高度和俯角等几何参数对标定结果进行独立物理一致性验证。
3. 标定 baseline 验证结果：OpenCV 标定结果 68.6847 mm，人工测量结果 70.0000 mm，误差 1.3153 mm（1.87898%）。人工测量参数仅用于物理 sanity check，不替代标定参数。
4. 完成 OpenCV 标定结果到 WASS 固定标定流程的接口适配，包括坐标约定、参数格式和 rectification 流程适配。
5. 完成手机双目静水面三维重建测试，验证从视频输入、标定、WASS 处理到三维点云输出的完整链路。
6. 单帧静水重建能够恢复水面平面，但跨帧深度稳定性不足。
7. 当前主要问题定位为近距离弱纹理水面场景下 StereoSGBM 双目匹配稳定性，而非标定或坐标转换问题。

当前状态：

- 标定参数：已获得，并完成物理一致性验证；
- WASS 接口：已完成固定标定接入；
- 静水重建：单帧水面平面恢复成功；
- 跨帧稳定性：正在优化双目匹配参数和物理视差约束。

## 近期工作路线

1. 优化 StereoSGBM 匹配参数，使静态水面跨帧重建稳定。
2. 验证静水参考面 Z0 的稳定建立。
3. 冻结标定和匹配配置后进入波浪视频重建。

## 范围

项目覆盖双目标定、影像校正、立体对应、三角测量、水面建模、高度定义、质量控制和误差分析。采集视频、大型数据集与 WASS 源码不属于本仓库的版本控制范围。

## 预期产出

1. 可追溯的系统与数学模型文档。
2. 与 WASS 输出对接的处理模块。
3. 像素级高度图、三维水面点云及质量掩膜。
4. 使用合成数据和实测数据的精度评估流程。
