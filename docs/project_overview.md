# 项目概述

## 目标

建立基于双目视觉的水面三维形态与高度测量系统。当前工程主线以一组同步左右图像为输入，经标定参数和 WASS 得到 XYZ、水面形态及相对参考水面的高度 `H(x,y)`；目标工程载体是专业双目相机，而不是实时波浪视频处理系统。

同步图像对可由专业双目相机直接采集，也可从已有双目视频中按已验证的时间关系抽取。视频是输入来源和扩展研究载体，不是单帧主流程的必要条件。

## 当前阶段进展

当前已完成支撑单帧主线的以下基础工作：

1. 接入 OpenCV 官方双目标定流程，完成相机内参、畸变参数和双目外参 K/D/R/T 求解。
2. 使用人工测量 baseline、相机高度和俯角等几何参数对标定结果进行独立物理一致性验证。
3. 标定 baseline 验证结果：OpenCV 标定结果 68.6847 mm，人工测量结果 70.0000 mm，误差 1.3153 mm（1.87898%）。人工测量参数仅用于物理 sanity check，不替代标定参数。
4. 完成 OpenCV 标定结果到 WASS 固定标定流程的接口适配，包括坐标约定、参数格式和 rectification 流程适配。
5. 完成手机双目静水面三维重建测试，验证从视频输入、标定、WASS 处理到三维点云输出的完整链路。
6. 建立 pixel–XYZ 对应和点到参考平面的水面高度计算。
7. 完成 wave、同步、性能、长时批处理和 production mode 扩展接口；这些历史成果保留，但不再作为当前主线。

当前状态：

- 标定参数：已获得，并完成物理一致性验证；
- WASS 接口：已完成固定标定接入；
- 静水重建：单帧水面平面恢复成功；
- 当前主线：单帧水面三维测量、独立物理验证和专业相机迁移。
- 动态视频：作为 Extension 保留；既有跨帧稳定性失败不被覆盖。

## 近期工作路线

1. 冻结单帧输入、标定、WASS、XYZ、pixel–XYZ 和高度输出接口。
2. 使用不参与解算的独立物理参考验证尺度与 `H(x,y)` 误差。
3. 建立结果展示软件，然后迁移到专业双目相机、硬触发和工程部署。
4. Wave video analysis 继续作为未来动态水面 Extension。

## 范围

项目覆盖双目标定、影像校正、立体对应、三角测量、水面建模、高度定义、质量控制和误差分析。标尺数据仅用于结果验证，不参与任何三维重建和高度计算流程。Ruler data is only used for independent validation and is not included in the reconstruction pipeline. 采集视频、大型数据集与 WASS 源码不属于本仓库的版本控制范围。

## 预期产出

1. 可追溯的系统与数学模型文档。
2. 与 WASS 输出对接的处理模块。
3. 像素级高度图、三维水面点云及质量掩膜。
4. 使用合成数据和实测数据的精度评估流程。
