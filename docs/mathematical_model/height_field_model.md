# 水面高度场模型

## 动态水面与静水参考

在统一世界/水槽坐标系和规则网格中，动态水面为

\[
Z(x,y,t),
\]

其中 `x,y` 为水平位置（m），`t` 为有效曝光时间（s），`Z` 为沿规定竖直轴的高程（m）。独立静水序列经过相同标定、尺度恢复、WASS 重建和网格化流程得到

\[
Z_0(x,y),
\]

其中 `Z0` 单位为 m。它可保留空间变化，不能未经验证就设为常数零平面。

## 最终输出

\[
H(x,y,t)=Z(x,y,t)-Z_0(x,y).
\]

`H` 单位为 m。竖直轴向上时，`H>0` 表示高于静水平均面。相减要求 `Z` 和 `Z0` 具有相同坐标系、原点、轴方向、物理尺度、网格和兼容质量掩膜；任一输入无效时 `H` 也无效。

| 输出字段 | 含义 | 单位/类型 |
|---|---|---|
| `x,y` | 水平网格坐标 | m |
| `t` | 有效曝光时间 | s |
| `Z` | 动态高程 | m |
| `Z0` | 静水平均面 | m |
| `H` | 相对高度 | m |
| `valid_mask` | 联合有效性 | boolean |
| `coordinate_reference` | 坐标变换与轴方向 | 元数据 |

静水相减是 WASS 输出后的项目后处理，不修改其核心算法。依据：[静水参考集成](../wass/static_water_reference_integration.md)、[WASS pipeline](../wass/pipeline_analysis.md)、[WASS 论文](https://www.dsi.unive.it/wass/papers/1-s2.0-S0098300417304302-main.pdf)。

本模型不依赖固定水槽尺寸；基线、工作距离、水槽范围、网格范围和网格间距均为 `UNKNOWN/TODO`。
