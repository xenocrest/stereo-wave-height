# HomeTank_006 部分棋盘补救：实际执行结果

## 数学依据与边界

OpenCV `calibrateCamera` 接受每个视角不同数量的真实三维格点与二维观测对应；每视角有独立棋盘位姿。采用 `findChessboardCornersSBWithMeta` 与 `CALIB_CB_LARGER` 检测至少7×4、最大由返回metadata决定的连续可见格点，不要求完整9×6。

依据：[OpenCV官方标定接口](https://docs.opencv.org/4.8.0/d9/d0c/group__calib3d.html)。本机OpenCV函数文档明确说明LARGER和meta支持超出视场的棋盘。

物点使用用户确认的20 mm名义格距。每帧局部原点可用于单目标定的独立位姿，但不能直接充当跨相机相同物理角点编号；没有把局部序号直接用于stereoCalibrate。没有合成被遮挡角点，没有使用旧标定、标尺或人工高度修正。

## 执行

入口：`tools/hometank006_partial_calibration.py`，从项目根目录运行。

每侧抽取5至105秒、间隔5秒，共21帧。显式关闭自动旋转，LEFT旋转180°。仅检测图像缩小到1/4，检测坐标乘4回原图并亚像素细化，标定图像尺寸保持3840×2160。

第一项固定7×4检测结果：LEFT 1/21、RIGHT 2/21；未做标定。

已查看LEFT 20秒及RIGHT 70秒角点覆盖图。图像可见手绘边界和灰度不均匀、遮挡；LEFT 80秒检测格点相邻间距还存在明显不均匀。无法仅凭本次试验分离目标不规则、错误角点和姿态约束不足各自贡献，不能宣称唯一根因。

部分检测成功，不等于标定成功；本轮没有新XYZ或高度，工程目标未完成。WASS执行0次，GUI和正式重建算法未修改。波浪帧级同步仍未建立。
