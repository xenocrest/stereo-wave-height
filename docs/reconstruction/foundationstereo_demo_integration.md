## 演示流程

保留三个步骤：标定加载/计算、双目视频选择、播放与 ROI/参考/解算/结果。
移除旧“最新实测结果（只读）”回放页面，不删除历史数据。
结果页不显示可信度评分，仅保留“模型估算”的数据来源标识；完整限制保存在 JSON 和报告中。

用户选择参考时刻后真实运行模型，在 ROI 内用左右一致点拟合参考平面；测量帧使用该固定平面。
采用 OpenCV 校正和 Q 重投影，高度为 `(n dot P+c)/norm(n)`，不是 camera Z。
左右图像保留实际解码时间。原图查询使用校正映射后的射线，不拉伸热力图、不更换 ROI、不替换时刻。
960×540 的官方预测用最近邻视差采样映射至原始像素；这不增加独立观测。
全部有限高度标为模型估算；无效区域保留 NaN，不随机填满。
独立标尺未参与解算。模型模式失败不会回退到历史 48 s WASS 结果。

## 本机接入

EXE 同目录的 `foundationstereo_runtime.json` 显式指定外部 Python、项目、官方源码和验证过的权重路径。
可通过环境变量 `STEREO_FOUNDATION_RUNTIME` 指定另一个配置；不配置时保持原后端。
参照 [运行时模板](../../packaging/foundationstereo_runtime.example.json)。
此次依赖已安装的外部 GPU 环境，不是可随意复制到另一台电脑的独立安装包。
官方源码和权重未嵌入或提交；再分发/商业使用需分别核验上游许可。
