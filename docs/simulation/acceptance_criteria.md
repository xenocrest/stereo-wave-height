# 无实体设备仿真验收标准

## 1. 声明范围

`1 cm = 0.01 m`。只有在预先冻结的仿真配置、独立评价脚本和 WASS 端到端输出上满足本文件门槛，才能称“仿真软件链满足厘米级数值目标”。该结论不能外推为真实水面、真实相机或现场系统达到 1 cm。

几何单元测试与 WASS 端到端验收分开报告。前者允许解析对应；后者禁止向 WASS 提供真值视差或真值点云。

## 2. 指标定义

在真值与计算结果的共同有效网格 `V` 上，误差为

\[
e_i=H_{calc,i}-H_{true,i},\qquad i\in V,
\]

其中 `H_calc,H_true,e` 单位为 m，`N=|V|` 为无量纲有效样本数。

\[
RMSE_H=\sqrt{\frac{1}{N}\sum_{i\in V}e_i^2},
\]

\[
MAE_H=\frac{1}{N}\sum_{i\in V}|e_i|,
\qquad
E_{max}=\max_{i\in V}|e_i|.
\]

有效点比例和空洞率为

\[
r_{valid}=\frac{N_{valid}}{N_{eligible}},
\qquad
r_{hole}=1-r_{valid}.
\]

其中计数均无量纲；eligible 区域是两相机真值可见、位于冻结 ROI 且非真值遮挡的格点，不能把几何不可见区计作 WASS 失败，也不能事后缩小 ROI。

三维尺度误差用已知真值长度 `L_true`（m）和重建长度 `L_calc`（m）定义：

\[
e_{scale}=\frac{|L_{calc}-L_{true}|}{L_{true}}.
\]

## 3. 预注册门槛

下列是项目仿真验收定义，不是 WASS 官方性能声明：

| 指标 | 几何单元测试 | WASS 端到端 | 说明 |
|---|---:|---:|---|
| 三维尺度相对误差 | ≤`1e-9` | ≤0.5% | 单元测试使用无噪声双精度解析输入；WASS 包含离散匹配 |
| Case 0 静水平面 RMSE | ≤`1e-9 m` | ≤0.005 m | 端到端为 1 cm 总目标保留预算 |
| `H_calc` 对 `H_true` RMSE | ≤`1e-9 m` | **≤0.010 m** | 核心厘米级数值门槛 |
| MAE | ≤`1e-9 m` | ≤0.010 m | 与 RMSE 同时报告 |
| 最大绝对误差 | ≤`1e-8 m` | ≤0.030 m | 防止少量大离群点被 RMSE 隐藏 |
| 有效点比例 | 100%（真值可见区） | ≥95% | 使用冻结 eligible ROI |
| 空洞率 | 0% | ≤5% | 与有效率使用同一分母 |

`1e-9` 和 `1e-8 m` 是无噪声解析几何实现的数值回归阈值，状态为 `software_unit_test_threshold`，不是传感器精度。若所用数值精度或实现无法满足，应在实现前修订并说明数值分析依据，不能在看到结果后放宽。

## 4. 符号与坐标验收

### Case 1 高度符号

分别运行正、负 `Delta H`。在有效区内要求：

- `sign(mean(H_calc)) = sign(Delta H)`；
- `|mean(H_calc)-Delta H|≤0.010 m`；
- 当 `|Delta H|≤0.010 m` 时，符号测试可能受容差支配，因此用于符号验收的 `|Delta H|` 必须大于 0.010 m；实际值仍是运行参数，默认 UNKNOWN。

### 坐标方向

- 增大真值 `x` 必须映射到声明的世界 `+x`；增大 `y` 同理；
- Case 2 的相位传播方向必须与 `kx-omega t` 的符号一致；
- Case 3 两个非平行波矢的重建方向分别与真值一致；
- WASS 坐标到仿真世界坐标的变换必须保存，禁止以翻转图像后“看起来正确”作为验收。

坐标方向为布尔门槛：任一轴、时间顺序或高度正负错误即失败。

## 5. 分 Case 验收

| Case | 必须通过的项目 |
|---|---|
| 0 静水平面 | 坐标/单位、静水 RMSE、平面度、有效率、空洞率 |
| 1 已知高度平面 | Case 0 全部、尺度误差、正负符号、均值高度误差 |
| 2 一维正弦波 | RMSE/MAE/max、振幅和传播方向、时间帧顺序 |
| 3 二维修正规则波 | RMSE/MAE/max、二维轴方向、两个波矢方向和有效覆盖 |

所有门槛必须在预先定义的全部 B/Z 扫描点和场景参数上逐项报告；不能只选择成功点汇总。

## 6. 配置与来源验收

- 仿真配置能追溯到 `configs/equipment/candidate_system.yaml`；
- 2448×2048、3.45 µm、8 mm 的值和状态一致；
- `2318.8405797 px` 标为 `SIMULATION_NOMINAL`，主点标为 `simulation_assumption`；
- 基线、工作距离和水槽尺寸在未配置时为 `null / UNKNOWN`；
- 理想零畸变不标为真实设备参数；
- 每个非空数值包含 unit、source、status，派生量包含公式。

任一来源或状态断裂即配置验收失败，即使数值误差指标通过也不能发布结论。

## 7. 结果报告

报告必须同时给出配置哈希、WASS 版本/配置、每个 Case 和扫描点的全部指标、失败帧、eligible ROI 定义及真值隔离证明。不得使用“理论可达”“仿真已达”替代真实设备验证结论。
