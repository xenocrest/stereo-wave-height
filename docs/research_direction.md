# 研究方向

## 核心问题

- 如何稳定完成低纹理、高反光、动态水面的双目匹配。
- 如何从视差与标定参数得到带有不确定度的三维水面。
- 如何定义局部参考水面并将三维点转换为像素级波面高度。
- 如何分离标定、同步、匹配、姿态和参考面误差。

## 当前主线定位

当前主线是面向专业双目相机的**单时刻水面三维形态与高度测量**：

```text
同步 left/right 图像
  → OpenCV K/D/R/T
  → WASS 三维重建
  → XYZ 与 pixel–XYZ
  → 参考水面法向高度 H(x,y)
  → 独立物理误差验证
```

图像对可以直接来自专业相机，也可以从已有视频抽取。连续 wave 视频、时间同步、长时批处理与 production mode 作为 Extension 保留，不是当前系统必须实时完成的主目标。

## 当前研究进展

### 1. 双目标定与工程参数验证

已完成 OpenCV 官方双目标定流程接入，并获得完整内参、畸变参数和双目外参。

通过人工测量 baseline、相机高度和俯角进行物理一致性检查：

- 标定 baseline：68.6847 mm；
- 人工测量 baseline：70.0000 mm；
- 相对误差：约 1.88%。

结论：人工测量参数仅作为物理 sanity check，不替代标定结果。实际重建优先使用标定得到的 K/D/R/T。

### 2. WASS 工程接入

已完成 OpenCV 标定结果到 WASS 输入格式的适配流程。

当前已解决：

- OpenCV 与 WASS 坐标约定统一；
- rectification 参数接口适配；
- 固定标定参数进入 WASS stereo 流程；
- 手机视频作为 Stereo Video File 输入验证。

### 3. 真实手机视频静水重建验证

已完成 HomeTank_004 静水面三维重建验证。

结果：

- 单帧可恢复稳定水面平面；
- 跨帧水面深度存在漂移。

当前判断主要原因：

- StereoSGBM 匹配稳定性不足；
- 手机近距离拍摄导致视差接近搜索上限；
- 水面纹理弱，导致有效匹配区域变化。

五帧 wave 扩展链已经闭环，但静态跨帧质量门仍失败；该结果作为动态扩展证据保留，不阻断单帧专业测量主线。

当前真实视频阶段不宣称 1 cm 精度。HomeTank_004 保持
`CALIBRATION_QUALITY_FAIL`、`STATIC_VALIDATION_FAIL` 和
`approved_for_wass=false`；这些状态不会因单帧平面重建成功而改变。

## 后续路线

1. 完成单帧测量结果 schema、质量门与结果展示接口；
2. 以独立标尺或其他可追溯参考评价尺度和高度误差，但参考数据不得反馈到重建；
3. 迁移至专业双目工业相机，复用已建立的标定、WASS 接口和质量控制流程；
4. 在硬件同步和独立物理参考条件下执行正式精度验收；
5. 后续再以 Extension 形式扩展连续动态水面和真实海浪。

标尺数据仅用于结果验证，不参与任何三维重建和高度计算流程。Ruler data is only used for independent validation and is not included in the reconstruction pipeline.
