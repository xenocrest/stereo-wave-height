# 双目测波系统总体设计

## 1. 项目目标

本系统最终以左右双目视频为输入。用户在软件播放器中选择目标时间 `t`，系统根据已验证的左右时间关系提取 `I_left(t)` 和 `I_right(t)`，再按需调用 WASS 完成一次单时刻水面三维重建，在统一坐标与物理尺度下得到水面高程 `Z(x,y)`；使用独立参考水面 `Z0(x,y)` 后输出：

$$
H(x,y)=Z(x,y)-Z_0(x,y)
$$

其中 `x,y` 为水平坐标（m），`Z`、`Z0` 和 `H` 单位均为 m。这里的 `t` 只用于视频选帧；单次结果仍为 `H(x,y)`。连续时间高度 `H(x,y,t)` 属于 wave video Extension。近期目标是建立 Video-based on-demand single-frame stereo measurement system；1 cm 是待独立物理验证的目标，不是当前性能声明。

采购前理想仿真和低成本真实视频第一轮闭环已经完成。当前主线是视频加载、交互选时刻、同步帧提取、按需单帧测量、独立验证和专业相机迁移。同步模块服务选帧但不进入重建数值链；连续 wave、长时批处理和动态波高保留为扩展层。WASS 仍保持外部只读。

## 2. WASS 框架定位

WASS 是本项目的核心外部依赖，负责经过验证的双目几何估计、自动标定、稠密立体重建和水面网格处理。本项目锁定：

- 上游：`fbergama/wass`；
- WASS：tag `v_1.5`，commit `59f1b1c46c41a7d0baf85fc2b21e062eaf552feb`；
- `wassgridsurface`：`0.11.4`。

本项目不复制或修改 WASS 源码，通过文件、配置和命令行边界调用锁定版本。项目自身负责实验数据接入、元数据、物理尺度核验、静水基准、质量控制、验收和结果归档。详细边界见 [WASS 架构分析](../wass/architecture_analysis.md) 与 [复现计划](../wass/reproduction_plan.md)。

## 3. 双目测量系统结构

系统由以下部分组成：

| 子系统 | 组成 | 职责 | 当前状态 |
|---|---|---|---|
| 双目成像 | 两台同步工业相机、镜头、偏振/照明附件（如需） | 采集重叠视场内的左右水面影像 | 相机和约 8 mm 镜头均为暂定/候选 |
| 机械结构 | 可调刚性基线、相机支架、水槽坐标控制点 | 保持相对姿态，提供可测基线与公共视场 | 待设计与验证 |
| 时间同步 | 硬触发源、触发线、时间戳与丢帧检测 | 使左右曝光对应同一水面时刻 | 候选相机支持外触发；曝光时差与抖动待实测 |
| 标定系统 | 标定板、尺度件、独立测量工具 | 求内参、检查外参、恢复尺度并验证误差 | 待选型 |
| 实验参考 | 静水液位参考、波高或位移参考 | 建立 `Z0` 并提供独立验收真值 | UNKNOWN/TODO |
| 采集与存储 | 双 USB3 主机、无损图像、元数据清单 | 可靠保存同步帧对和实验谱系 | 手机输入已验证；专业采集待验证 |
| 重建环境 | 锁定版本 WASS 与 `wassgridsurface` | 运行标准三维重建链 | 仿真和真实单帧均已跑通 |
| 项目后处理 | 坐标统一、参考面、高度、质量指标和报告 | 从 WASS 输出得到 `H(x,y)` | 核心接口已实现 |

候选 MER2-503-36U3C 为彩色全局快门相机，公开格式为 BayerRG8/10；正式输入策略和未确认项见 [水槽尺度适配论证](../wass/lab_scale_adaptation.md)。

## 4. 坐标系与变换

为避免把像素、相机深度和水面高程混用，系统区分以下坐标系：

### 4.1 图像坐标系

- 左图：`I0`，像素坐标 `(u0,v0)`，单位 px；
- 右图：`I1`，像素坐标 `(u1,v1)`，单位 px；
- 经去畸变和极线校正后，视差为 `d=u0-u1`，单位 px；具体符号以实际 WASS 校正输出验证。

### 4.2 相机坐标系

- `C0`：左相机光心坐标系；
- `C1`：右相机光心坐标系；
- 两者通过旋转 `R`（无量纲）和平移 `T`（尺度恢复前可能为归一化单位）关联；
- 物理基线 `B=||T||`，单位 m，必须通过可追溯测量和刚体尺度验证恢复。

### 4.3 重建与水槽坐标系

- `C_R`：WASS 重建坐标系，由锁定外参和尺度变换定义；
- `C_W`：水槽/世界坐标系，`X_W,Y_W` 沿静水面，`Z_W` 沿规定的竖直正方向；
- `C_G`：规则网格坐标系，以 `(x_i,y_j)` 标识固定格点。

从 `C_R` 到 `C_W` 的刚体或相似变换必须由静水平面、控制点和尺度件确定并记录。坐标轴正方向、原点、长度单位及变换矩阵是每次实验的必备元数据。不得仅凭可视化方向判断高度正负。

## 5. 静水面高度定义

动态水面和静水面必须位于同一物理尺度、坐标系和规则网格：

$$
Z(x_i,y_j,t)\in\mathbb{R}\ \mathrm{m},\qquad
Z_0(x_i,y_j)\in\mathbb{R}\ \mathrm{m}
$$

最终高度为：

$$
H(x_i,y_j,t)=Z(x_i,y_j,t)-Z_0(x_i,y_j)
$$

当 `Z_W` 规定为向上为正时，`H>0` 表示高于静水平均面，`H<0` 表示低于静水平均面。静水参考由独立静水同步序列经过同一 WASS 流程得到，并在 WASS 输出之后进行平均、拟合与相减；不得修改 WASS 核心算法。详细规则见 [静水参考集成设计](../wass/static_water_reference_integration.md) 和 [高度定义](../mathematical_model/height_definition.md)。

## 6. 端到端数据流程

```text
实验配置与版本冻结
  → 专业相机采集 left/right 视频
  → 软件加载视频并建立左右时间对应
  → 用户播放、选择并暂停于目标时间 t
  → 提取 I_left(t), I_right(t)
  → 帧对身份/时间戳一致性检查
  → Bayer 数据固定转换为 8-bit 灰度无损图像
  → 相机内参文件和 WASS 工作目录
  → wass_prepare
  → wass_match
  → wass_autocalibrate
  → 物理尺度恢复与刚体尺度核验
  → wass_stereo
  → 点云/网格质量检查
  → wassgridsurface 统一规则网格
  ├─ 独立参考采集 → Z0(x,y)
  └─ 被测同步帧对 → Z(x,y)
  → H(x,y)=Z-Z0
  → 质量掩膜、误差指标、NetCDF/轻量报告
```

### 6.1 输入

- 左右视频、用户选择时间 `t`、对应同步帧及不可重复的帧对 ID；
- 原始触发计数、设备/主机时间戳和丢帧记录；
- 两相机内参、畸变参数和标定报告；
- 镜头、曝光、增益、分辨率、基线、工作距离和环境元数据；
- WASS 和网格化配置及版本标识。

### 6.2 中间数据

- 去畸变/校正图像；
- 稀疏匹配、外参和质量日志；
- 稠密视差、三维点云、平面和有效区域；
- 物理尺度变换及统一网格。

### 6.3 输出

- 单时刻高程 `Z(x,y)` 与静水参考 `Z0(x,y)`；
- 相对高度 `H(x,y)`；
- 每格点/每帧质量掩膜；
- 标定、同步、匹配、空洞率和高度误差统计；
- 可追溯的配置、输入清单、软件版本和实验报告。

视频、完整图像序列、点云和大型 NetCDF 不提交 Git；仓库只保存小型配置、清单、指标和文档。

## 7. 实验路线

### 7.1 基础几何验证

使用标定板、刚体平面和已知长度件，验证内参重投影误差、尺度、不同深度的平面度、公共视场和三角化有效性。此阶段不使用动态水面宣称精度。

### 7.2 静水验证

冻结成像和几何参数，采集独立静水序列；运行完整 WASS 链，建立 `Z0(x,y)`，检查时间漂移、空间平面度、覆盖率和重复性。

### 7.3 单帧高度与独立物理验证

在同一安装与标定下采集一组被测水面同步图像，以独立标尺、位移或其他可追溯参考验证 `H(x,y)`。验收至少包括高度 RMSE、偏差、最大误差、空洞率、匹配有效率和标定重投影误差。标尺数据仅用于结果验证，不参与任何三维重建和高度计算流程。Ruler data is only used for independent validation and is not included in the reconstruction pipeline.

### 7.4 结果展示、专业相机迁移与动态扩展

单帧物理验证后建立结果展示、质量门控和数据管理，再迁移专业相机、硬触发、镜头与刚性安装。连续 wave 视频、批处理、漂移检测和真实海浪属于 Extension；扩展时必须重新设计同步、工作距离、基线、焦距、帧率、环境防护和误差预算。

阶段计划见 [PROJECT_PLAN.md](../PROJECT_PLAN.md)，量化验收见 [1 cm 误差预算](../wass/one_cm_error_budget.md)。

## 8. 软件架构

软件采用分层、文件驱动的边界设计；这里只定义职责，不创建代码：

| 层 | 职责 | 与 WASS 的关系 |
|---|---|---|
| 数据接入层 | 校验同步帧、转换图像、生成输入清单和元数据 | 在 WASS 之前，不改变匹配算法 |
| 标定与尺度层 | 管理内参、外参输入、基线和控制点尺度验证 | 按 WASS 文件格式提供输入并核验输出 |
| WASS 执行层 | 调用 prepare、match、autocalibrate、stereo | 上游只读、版本锁定 |
| 网格化层 | 使用锁定 `wassgridsurface` 生成共同网格 | 外部依赖只读 |
| 高度后处理层 | 构建 `Z0`、计算 `H=Z-Z0`、传播质量掩膜 | 本项目功能，不替代立体算法 |
| 验证层 | 计算平面度、尺度、同步、匹配、空洞和高度误差 | 独立评价 WASS 输出和完整测量链 |
| 归档层 | 保存配置、版本、清单、指标和报告 | 确保数据谱系与复现性 |

层间接口必须显式记录坐标系、单位、数组形状、无效值、质量掩膜、时间戳和版本。任何自动过滤都必须可追溯，不能静默删除失败帧或用插值值冒充有效测量。

### 8.1 最终软件的输入、交互、计算与展示边界

```text
视频层
  StereoVideoSource(left video, right video)
        ↓
交互层
  Video Player → Time Selection → Pause / Submit Measurement
        ↓
计算层
  Time Mapping → StereoFramePair(I_left(t), I_right(t))
  → Calibration → WASS → XYZ → Pixel–XYZ → H(x,y)
        ↓
展示层
  Point Cloud → 3D Surface → Height Map → Statistics / QA / Export
```

`StereoFramePair` 之后的处理不得识别手机或相机型号。同步模块只负责把用户时间映射成左右视频时间并选择帧；它不得修改图像、WASS、XYZ 或高度。专业相机优先使用硬触发和硬件时间戳写入视频时间轴。若同步置信度不足，按需任务必须拒绝运行，不能假设左右帧号相同。

核心后端使用 `SingleFrameMeasurementRequest → SingleFrameMeasurementResult` 边界。结果 JSON 直接提供请求/实际时间、pair residual、帧 ID、标定来源、XYZ 和 pixel–XYZ 数量、参考平面、高度统计、QA、警告及输出路径；GUI 不需要解析 WASS 原始日志。请求支持 `image_pair` 与 `video_time`，两种模式在生成 canonical selected pair 后共享同一 fixed-calibration reconstruction pipeline，且永不调用 `wass_autocalibrate`。

### 8.2 桌面程序 V0.x

桌面程序暂用名称 **Stereo Wave Height Measurement System**。V0.x 包含 Video Input/Player、Time Selection、Calibration、On-demand Reconstruction、3D Surface、Height Map、Point Height、QA / Export 页面。用户播放视频时不运行 WASS；只有暂停并提交目标时间后才创建单帧任务。GUI 读取统一任务结果，缺失或未知 metadata 必须显式失败/显示 `UNKNOWN`。

### 8.3 既有模块的产品角色

| 模块 | 当前角色 | 禁止越界 |
|---|---|---|
| 视频同步 | 确定 `t` 对应的左右视频时间与帧 | 不进入 WASS、XYZ 或高度计算 |
| Production mode | 单帧结果保存、任务状态、恢复与软件接口 | 不修改 WASS 数值结果 |
| Wave/长时处理 | 未来连续动态测量 Extension | 不作为当前交付阻塞项 |
| 标尺验证 | 重建完成后的 Independent Validation | 不进入匹配、三角化、参考面或高度计算 |

## 9. 设计约束与当前未知项

- 不修改 WASS 上游源码，不原创替代核心立体匹配；
- 不与旧 `lanhung/wave-height` 项目混合；
- 候选相机、约 8 mm 镜头和基线均未形成采购结论；
- 镜头准确型号、相机同步抖动、目标波频、工作距离、水槽 ROI 和参考仪器为 `UNKNOWN/TODO`；
- 未完成 WASS 实机复现和水槽实验前，不声明达到 1 cm；
- 真实海浪扩展必须经过新的尺度分析和现场验证。
