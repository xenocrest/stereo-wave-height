# 真实水面图像、三维支持区域与 WASS 点云

本目录展示项目历史真实手机双目视频实验中，同一组双目帧、其真实 WASS 三维重建点，以及这些三维点在 RIGHT/cam1 原图中的实际投影位置。

- Dataset：HomeTank_005
- 角色：真实波浪 measurement
- Requested time：68.501800 s
- Actual time：LEFT 68.512567 s，RIGHT 68.501800 s
- Frame ID：LEFT `pts_6166131`，RIGHT `pts_6165162`
- Calibration：HomeTank_005_demo_only_v1
- XYZ：117,450 个，全部有限
- 投影：117,450 / 117,450 位于 1920×1080 图像内
- 历史 ROI 内投影：86,978 个

三联图中：

1. 左图是该 measurement 保存的真实 RIGHT/cam1 输入帧。
2. 中图黄色点是逐点 XYZ 对应像素经历史标定映射回 canonical RIGHT/cam1 后的位置，红线是全部投影点的凸包边界，蓝线是历史 ROI；黄色区域不是人工圈选的“全部水面”。映射抽样的正反变换最大闭环误差为 0.312 px。
3. 右图是同一文件中的 117,450 个真实 WASS XYZ，仅按原始 Z/depth 着色。

图像、XYZ、逐点像素映射、左右实际时间和帧 ID 都来自同一运行目录，因此同源关系可以核查。最终 PLY 未删除离群点，未旋转、缩放、拉平或改变任何坐标；静态图只改变观察相机视角并作确定性显示抽样。

相比 44.3345 s 案例，本案例的点云主体更连续、悬空离散结构更少，并且映射证据完整，因此更适合汇报。该选择只是展示质量判断，不代表独立证明了更高测量精度。

该历史运行存在 reference/measurement 坐标不兼容警告，因此本展示只证明真实 XYZ 三维重建及其图像支持位置，不使用历史高度结果进行物理精度声明。
